# Backend Pipeline Notebook

Open `backend_pipeline_walkthrough.ipynb` in Jupyter or VS Code.

The notebook is standalone and does not import the application code. It recreates the backend logic step by step so the pipeline can be explained in class:

- policy setup
- document validation
- use-case confidence scoring
- user-level routing
- query validation
- scoped retrieval
- answer generation
- output validation
- approval queue
- audit trail
- feedback capture

Run the cells from top to bottom.
